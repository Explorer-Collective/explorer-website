# Explorer Website

探索者（Explorer Collective）官方网站源码。

## 线上地址

<https://explorer.org.cn/>

## 本地预览

在仓库根目录启动静态 HTTP 服务：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。
